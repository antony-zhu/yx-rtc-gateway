## 2. 约定

表格字段说明：

| 字段 | 说明 |
| --- | --- |
| 参数 | 参数路径或固定常量名 |
| 默认值 | 未收到平台配置、出厂配置或脚本传参时使用的值 |
| 可配置 | `是` 表示平台或设备参数可改；`否` 表示当前版本固定；`出厂` 表示只应在出厂阶段写入 |
| 存储位置 | `NVS` 表示系统参数，必须加密保存；`固件常量` 表示编译期固定；`cfgfs`/`datafs`/`logfs` 表示 LittleFS 分区 |
| 恢复出厂 | `保留`、`清除`、`清除后回默认`、`重建` 或 `不适用` |
| 生效时机 | 修改后何时生效 |
| 备注 | 合法范围、限制或模块引用 |

系统参数存储原则：

1. 设备系统参数统一保存在 NVS，并按 `06-模块设计-存储与文件系统.md` 的 AES-256-CTR 规则加密。
2. 用户自己的参数保存在当前生效配置区的 `config.json` 或用户脚本创建的 `datafs:/` 文件中。
3. 脚本运行时创建的数据只允许放在 `datafs:/`。
4. 固件常量不允许通过 MQTT 修改；如后续需要开放，必须先更新本文档和对应协议文档。
5. 本文档中的 `MB` 按固件文档现有约定理解；涉及精确字节的参数已直接给出字节数。

## 19. 参数归属和恢复出厂汇总

恢复出厂必须保留：

| 数据 | 说明 |
| --- | --- |
| 硬件 MAC | 从芯片读取，不清除 |
| 固定 `device_id` | 每次启动和恢复出厂均由硬件 MAC 校验/重建，历史自定义值不得保留 |
| `product_id` | 出厂写入，当前默认 `yx_gw` |
| `group_id` | 出厂写入，当前联调阶段暂时使用 `yx_gw` |
| 出厂必要参数 | 当前包括 `product_id`、`group_id` 和 `device_id`；MQTT 信息按恢复出厂规则清除 |

恢复出厂必须清除：

| 数据 | 说明 |
| --- | --- |
| MQTT 连接信息 | 清除后必须由出厂/维护工具重新写入 |
| 运行参数 | 心跳、授时、HTTP 超时、MQTT 重连、健康监控等清除后回默认 |
| 配置双区 | 清空 `cfgfs:/cfg_a` 和 `cfgfs:/cfg_b` |
| 用户数据 | 清空 `datafs:/` |
| 运行日志 | 清空 `logfs:/` |
| OTA 临时状态 | 清除当前 OTA 阶段和目标版本 |
| 运行统计 | 清除重启次数、故障计数和启动风暴窗口 |
| `last_trusted_utc` | 清除后重新等待可信时间 |

不属于系统参数：

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 用户业务配置 | 当前生效配置区 `config.json` | 由配置包管理 |
| 用户脚本数据 | `datafs:/` | 由脚本读写，恢复出厂清除 |
| 用户脚本 MQTT/HTTP 参数 | `config.json` 或脚本代码 | 不写入系统 NVS |
| 运行日志内容 | `logfs:/log_*.jsonl` | 恢复出厂清除 |

## 20. 修改生效规则

| 参数类型 | 生效规则 |
| --- | --- |
| MQTT 连接参数 | 一般下次 `dev_mqtt` 连接生效 |
| MQTT 发布参数 | QoS、retain 可在下次发布或订阅生效 |
| HTTP 超时和重试 | 下次 HTTP 请求生效 |
| 4G APN | 下次 4G 拨号生效 |
| 心跳间隔 | 下一个心跳周期生效 |
| 授时间隔和方式 | 下次授时周期生效 |
| 日志保留和容量 | 下次日志扫描或清理生效 |
| 脚本异常策略 | 下次脚本异常生效 |
| 配置包内容 | 配置更新成功并重启后生效 |
| OTA 固件 | OTA 成功并重启后生效 |
| 任务栈大小 | 固件重新编译并重启后生效 |

## 21. 待确认或后续扩展项
