添加设备到设备组

入口：设备管理 / 项目详情 / 设备组详情。用户看不到未分配池列表。
校验规则 输入设备编号并选择目标设备组后，后端校验设备是否在未分配池、是否未绑定、产品型号是否匹配目标设备组。
不会展示池列表 用户只输入设备编号，不浏览全局未分配设备池。

新增产品型号

仅平台管理员可操作。产品型号声明硬件产品身份；配置能力由固件版本声明。
可选 勾选后同时新增固件版本，固件自动关联当前产品型号，并录入固件配置能力清单。
固件配置能力 系统变量、系统函数、固件预置自定义变量/函数、网络通道槽位和硬件通道类型都跟随固件版本；产品型号只约束固件是否适用。
配置项稳定键固件默认迁移要求
系统变量deviceId / firmwareVersion只读，运行时注入稳定键不可复用
网络通道槽位net_mqtt / net_http / net_ws3 个槽位，可启停和配置参数升级时按 channelId 映射
硬件通道类型serial_com1 / rs485_bus1UART、RS485、I2C、SPI 参数表升级时校验通道是否保留
预置函数/变量parse_modbus_float / temperature_threshold随固件模板带出类型变更需要迁移提示

新增固件版本

仅平台管理员可操作。固件版本保存配置能力清单，设备组只引用并填写配置值。
1. 基础信息产品型号、版本、固件包和 SHA256
2. 能力清单系统变量、函数、通道槽位和预置项
3. 迁移规则稳定 Key 映射、默认值和废弃项
4. 校验发布草稿校验后发布为可用版本
复制新增 推荐从同产品型号上一固件复制能力清单，再只处理差异；后端按稳定 Key 生成迁移校验。
系统变量 6 deviceId、projectId、groupId、productModel、firmwareVersion、timestamp
函数 11 系统函数 8 个，固件预置函数 3 个；只读提供给数据流和用户函数引用。
通道槽位 7 网络通道 3 个，硬件通道 4 个；设备组只能配置启停和参数值。
能力项稳定 Key来源迁移处理
网络通道net_mqtt / net_http / net_ws固件声明保留旧通道；新增 net_ws 默认停用
硬件通道serial_com1 / rs485_bus1 / i2c1 / spi1固件声明保留串口参数；新增 SPI 默认停用
预置变量temperature_threshold / raw_prefix固件预置按 Key 自动迁移，bytes 使用 AA 55 格式
预置函数firmware_frame_unpack / gle_filter固件预置函数 ID 稳定，展示名可变
